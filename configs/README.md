# Configuration records

- `overall_model_configurations.json` records the selected configuration of each model on each panel
  for the overall fixed-holdout comparison.
- The Fig. 7 scaling experiment is a separate experiment. Its exact panel, ratio, model, seeds, sample
  counts, marker counts, source hashes, and scores are stored in `../results/fig7_three_seed_scaling.csv`.
  Those configurations must not be described as identical to the overall-comparison configurations.
